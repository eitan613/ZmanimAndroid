Timezone boundaries contain information from OpenStreetMap contributors and
Timezone Boundary Builder, licensed under the Open Database License 1.0.

The packaged boundaries preserve the source polygons, indexed with coordinates
stored as IEEE 754 floats. The source release URL is recorded in place-data.json.
The transformation is reproducible with tools/prepare_places.py.

Calculations use KosherJava Zmanim 3.0.0 by Eliyahu Hershfeld and contributors,
licensed under LGPL-2.1-or-later. The application calls the library directly.
https://github.com/KosherJava/zmanim

Reviewed locality presentation/defaults: selected GeoNames records are matched by
stable ID, names and coordinates to the Israel Central Bureau of Statistics 2023
locality file (coordinates EPSG:2039 converted to WGS84 at build time). The full
review table and original source coordinates are in locality-corrections.json.
https://data.gov.il/he/datasets/lamas/localities-in-israel/d47a54ff-87f0-44b3-b33a-f284c0c38e5a
Display country, civil timezone and Israel holiday default are independent values.
No blanket conversion is applied to PS records. Battir's erroneous Hebrew alias
for nearby Betar Illit is excluded from app search. This is app presentation and
calculation metadata, not a boundary dataset modification.

Optional elevation: Open Topo Data public API / SRTM90m. USGS/NASA SRTM terrain
height, meters above EGM96 mean sea level, 90 m horizontal resolution, coverage
60 degrees south to 60 degrees north. Public domain SRTM data. User coordinates
are sent only on Look up elevation; returned coordinates/result/dataset/time are
cached. Interpolation is the service default (bilinear); terrain does not model
buildings or local horizon obstruction. Service limits: 1 request/second,
1,000 requests/day, no availability guarantee.
https://www.opentopodata.org/datasets/srtm/
https://www.opentopodata.org/
